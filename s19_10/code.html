1. ตรวจชื่อบัญชีตรงกับชื่อโปรไฟล์แล้วใช่ไหม?

ชื่อบัญชีรับเงินต้องตรงกับชื่อเจ้าของโปรไฟล์หรือบัตรประชาชน ระวังบัญชีม้าที่ชื่อไม่ตรง

pin_drop

2. ได้ Proof Code จากคนขายแล้วใช่ไหม?

คนขายถ่ายรูปคู่กับรหัสป้ายชื่อจริง ยืนยันว่ามีสินค้าในมือ ไม่ใช่รูปดึงมาจากเน็ต

payments

3. ราคานี้สมเหตุสมผลใช่ไหม?

ไม่ถูกต่ำกว่าราคาตลาดจนน่าผิดปกติ (เช่น ถูกกว่า 50%) สินค้าราคาถูกเกินจริงมักเป็นเหยื่อล่อ
